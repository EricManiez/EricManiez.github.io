En 2022, quand je bascule à plein temps sur la pédagogie musicale, je
tiens à ne pas laisser la pratique du code s’atrophier. **MuseScore** —
le logiciel libre de référence pour la notation musicale — s’est imposé
comme le bon endroit : une base de code C++ mature et volumineuse, une
communauté active, et un domaine qui me tient à cœur.

Les contributions sont volontairement petites et soigneuses. L’enjeu
n’est pas de livrer des fonctionnalités spectaculaires, mais de rester
fluide : lire du code que je n’ai pas écrit, respecter des conventions
de revue, travailler dans une culture d’équipe que je ne façonne pas.
