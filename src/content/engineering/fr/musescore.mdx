Quand je bascule à plein temps sur la pédagogie musicale en 2022, je
tiens à ne pas laisser la pratique du code s’atrophier. **MuseScore** —
le logiciel libre de référence pour la notation musicale — est devenu
le bon endroit : une base de code C++ mature et costaude, une
communauté vivante, et un domaine qui me tient à cœur.

Les contributions sont volontairement petites et soignées. L’enjeu
n’est pas de livrer des fonctionnalités spectaculaires, mais de rester
à l’aise : lire du code que je n’ai pas écrit, respecter des
conventions de revue, et travailler dans une nouvelle culture d’équipe.
